Para quéQue el reintento nunca procese, incremente o borre la factura equivocada.
Cómo funcionaEl servicio genera el UUID al encolar (y se lo asigna a los registros antiguos); el job pide eliminar o incrementar por id.

Código:

// FacturaPendienteService.java
factura.put("id", UUID.randomUUID().toString());

public synchronized void eliminarPorId(String id) {
    List<Map<String, Object>> pendientes = leerPendientes();
    boolean eliminada = pendientes.removeIf(f -> id.equals(f.get("id")));
    if (eliminada) guardarPendientes(pendientes);
}

8. Seguridad de rutas (path traversal)

Qué se hizoLos endpoints que leen XML solo aceptan archivos de carpetas autorizadas y ya no muestran errores internos.
DóndeRutaArchivoService.java (archivo nuevo)  |  application.properties:24  |  DianController.java:43-92  |  TestController.java:37-56
Para quéEvitar que alguien lea archivos ajenos del servidor y no filtrar datos internos.
Cómo funcionaSe resuelve la ruta canónica y se compara con las carpetas base; si no está dentro responde 400 "Acceso Denegado". Para sumar una carpeta se agrega en app.rutas.permitidas.

Código:

// RutaArchivoService.java - resolverPermitido()
File archivo = new File(ruta).getCanonicalFile();
Path destino = archivo.toPath().toAbsolutePath().normalize();
for (String base : basesPermitidas()) {
    if (destino.startsWith(Paths.get(base).toAbsolutePath().normalize())) {
        return archivo;   // permitido
    }
}
return null;   // fuera de las carpetas autorizadas
